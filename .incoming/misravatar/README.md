# حارس المجد المصري — استوديو التعليم والشخصية التفاعلية

موقع عربي مبني بـ React وThree.js وVite. يحافظ على الرجل المصري الواقف وملامح/طربوش النسخة الحالية والهيكل الأصلي وحركة `idle`. أضيفت مساحة تعلم محلية فيها دروس JavaScript، محرر، فحص أولي للأقواس، Console وتشغيل بإجراء صريح داخل iframe معزول، إلى جانب نقاط واسم اختياري محفوظين محليًا.

## التشغيل المحلي

يتطلب Node.js 22 وpnpm 11.25.0. من جذر المشروع:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

للتدقيق والبناء:

```bash
pnpm typecheck
pnpm build
pnpm preview
```

يعمل Vite على المنفذ 3000. لا يحتاج هذا الإصدار إلى خادم أو قاعدة بيانات أو مفتاح API.

## مختبر التعليم

من رابط «مختبر التعليم» يمكن اختيار أحد دروس المتغيرات أو الشروط `if` أو حلقات `for`. النص والكود والتقدم والاسم الاختياري تحفظ داخل `localStorage` في المتصفح الحالي؛ زر «حذف بياناتي» يمسح الملف والنقاط والمسودات المخزنة. لم يُنفذ تعرف على الوجه.

لتشغيل الكود، راجعه ثم اضغط زر التشغيل. يجري التنفيذ في `iframe` يحمل `sandbox="allow-scripts"` من دون `allow-same-origin`، مع تعطيل اتصالات الشبكة عبر CSP، وتحديد لطول الإدخال وعدد/حجم مخرجات Console، وإعادة إنشاء الإطار بعد مهلة ثانيتين أو عند الإيقاف. هذا احتياط تعليمي يقلل الصلاحيات، وليس ضمان أمان مطلقًا؛ لا تستخدمه لشيفرات لا تثق بها. الكود لا يذهب إلى خادم ولا ينفذ على الخادم. فحص الأقواس والاقتباسات مساعد أولي وليس محلل JavaScript كاملًا.

تستخدم قراءة الدرس `SpeechSynthesis` المدمجة في المتصفح إن توفرت؛ تختار صوت `ar-EG` ثم أي صوت عربي متاح، ولا تضمن لهجة مصرية أو جودة موحدة. نص الدرس ظاهر حتى عند غياب الصوت. وضع الليل يعتمد ساعة الجهاز المحلية من 00:00 إلى 06:00، ويمكن تعطيله؛ يغير الألوان وسرعة القراءة المحلية فقط.

## الشخصية والأصول

- `public/hero-citizen-active.glb`: جسم الشخصية المصرية الواقف، هيكله الأصلي وحركة `idle`.
- `public/egyptian-fez-head.glb`: الرأس والطربوش المرتبطان بعظمة `Head`.
- `public/office-tea-scene.webp`: صورة المكتب والشاي محلية حتى يعمل الموقع بعد فك الحزمة خارج Manus.
- `public/review/egyptian-citizen-highdetail.glb`: أصل اختياري للمراجعة والتنزيل، وليس النموذج الرئيسي.

الصوت لا يحرك الفم في هذه النسخة؛ ملف الرأس الحالي لا يحتوي فكًا أو `visemes/blendshapes`. كما أن حركات الإشارة/High-Five والطربوش والكأس ثلاثي الأبعاد ليست متاحة في حركة `idle` الحالية.

## ميزات مؤجلة وغير مفعلة

يظهر الموقع أماكن جاهزة لربط Qwen/TTS، ومزامنة الشفاه، والكاميرا وMediaPipe، وإشارات اليد والنظر، والتشخيص البرمجي الدقيق، والاحتفال/المكافآت ثلاثية الأبعاد. لم تُفعّل خدمة خادمية ولم يُطلب أو يُضمّن مفتاح Qwen، ولا تبدأ الكاميرا ولا تُرفع صور/فيديو/صوت/كود. راجع `plan.md` و`TODO.md` و`technical-research.md` للتبعيات والحدود والمصادر الرسمية.

## التفاعل مع الشخصية

اسحب لتدوير المجسم، واستخدم عجلة الفأرة أو القرص بإصبعين للتقريب والإبعاد. تتوفر أزرار التدوير التلقائي وإعادة الضبط وملء الشاشة، ووضع WebXR على الأجهزة والمتصفحات الداعمة؛ يبقى العرض العادي متاحًا إن لم يدعم الجهاز WebXR.
