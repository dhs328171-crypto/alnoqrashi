# نتائج المشروع ومعايير الإنجاز

## الشخصية الحالية — محفوظة

- [x] **الشخصية والهوية:** يبقى جسم الرجل المصري الواقف وبدلته وطربوشه وملامحه كما هي، ولا يستبدل بروبوت أو نموذج جالس.
- [x] **الهيكل والحركة الأساسية:** يستمر استخدام GLB الأصلي المهيكل وحركة `idle`، والرأس/الطربوش الحاليان؛ لا إعادة هيكلة مدفوعة ولا تعديل لجسم الشخصية.
- [x] **العرض والتفاعل:** الموقع عربي RTL ومتجاوب؛ يدعم تدوير الشخصية بالسحب، التكبير، إعادة الضبط، ملء الشاشة وWebXR عند توفره، مع شرح عربي محلي.

## تعليم محلي ينفذ في هذه النسخة

- [x] **استوديو الدروس والمحرر:** يستطيع المتعلم اختيار درس JavaScript عربي، قراءة شرح مختصر، تعديل الكود في محرر داخل الصفحة، ورؤية أرقام الأسطر؛ تغيير الدرس لا يفقد التعديل بصمت، والمسح يحتاج تأكيدًا مع إمكانية استعادة المحتوى السابق.
- [x] **تشغيل ومعاينة تعليمية:** تشغيل الكود يحدث فقط بعد ضغط المتعلم زر التشغيل، داخل `iframe` معزول لا يملك `allow-same-origin`، وتظهر مخرجات Console النصية. يستطيع إيقاف/إعادة ضبط الإطار؛ لا يُنفذ الكود على الخادم ولا يُرسل إلى Qwen. هذه طبقة عزل محدودة وليست ضمانًا لانعدام المخاطر.
- [x] **التشخيص والتلميح:** تعرض النسخة المحلية فحوصًا أولية لأزواج الأقواس والاقتباسات غير المغلقة، وتُبرز سطرًا عند اكتشافها إن أمكن. يجب توضيح أن هذا ليس محلل JavaScript كاملًا؛ التشخيص الشامل للسطر والعمود ومؤشر الشخصية يحتاج محررًا/محللًا مخصصًا.
- [x] **التقدم والهوية اليدوية:** يمكن للمتعلم إدخال اسم اختياري بنفسه وتسجيل الدروس المكتملة والنقاط في تخزين المتصفح المحلي، مع استئناف آخر درس وكود محفوظ؛ لا يوجد تعرف على الوجه ولا رفع بيانات، ويمكن مسح التقدم المحلي.
- [x] **الصوت المتاح محليًا:** يستطيع المتعلم الاستماع إلى نص شرح الدرس بواسطة `SpeechSynthesis` إن دعم المتصفح صوتًا عربيًا، ويمكنه تشغيل تحية يذكر فيها اسمه اليدوي وآخر درس؛ يظهر النص دائمًا. لا يُضمن الصوت المصري أو مزود Qwen أو مزامنة الشفاه بهذه النسخة.
- [x] **الهدوء الليلي المحلي:** بعد منتصف الليل وحتى السادسة صباحًا حسب ساعة الجهاز، يمكن تفعيل ألوان أدفأ وقراءة أقل سرعة/حدة، مع زر تعطيل؛ تظل وضوح النص ومستوى الصوت للمستخدم قابلين للتحكم.

## مواضع جاهزة — غير مفعّلة وتحتاج اعتمادًا لاحقًا

- [ ] **Qwen وTTS ومزامنة الوجه:** المطلوب الأصلي هو محادثة تفاعلية تتكلم باللهجة المصرية، وتحريك الشفاه والفك والوجه في الزمن الحقيقي مع الصوت. لا تملك أصول الرأس الحالية فكًا أو `blendshapes/visemes`؛ تبقى هذه نقطة تكامل مرئية غير متصلة. يلزم وسيط خادم ومفتاح Qwen بصيغة آمنة، اختيار صوت مصري متاح/مرخص، وأصل وجه متوافق قبل ادعاء المزامنة.
- [ ] **الحركة والإشارة التعليمية:** المطلوب تنفس وتأرجح ورأس أثناء الصمت/الاستماع، إيماءات نحو سطر أو شرط `if`، توجيه الرأس إلى الخطأ، واحتفالات مثل High-Five أو تعديل الطربوش. لا ينسب هذا الإصدار حركة ذراع/يد جديدة إلى GLB الحالي؛ يلزم فحص أسماء المفاصل وإضافة/اعتماد تحريك متوافق مع بقاء الجسم والهيكل القديمين.
- [ ] **الكاميرا والإدراك المحلي:** المطلوب تتبع اليد وتعبير/وضعية الطالب، وإمكانية إيقاف الشرح عند الاشتباه في الحيرة مع الجملة «بصك لي كدة بيقول إنك تورت يا باشمهندس، تعال نعيد الحتة دي بشكل أسهل». الكاميرا غير مطلوبة ولا تبدأ في هذه النسخة. يلزم اختيار صريح من الطالب، وإذن المتصفح، معالجة MediaPipe محلية، مؤشر تشغيل وإيقاف فوري وبديل يدوي. الإشارات تقديرات وليست تشخيصًا نفسيًا.
- [ ] **الانتباه المشترك وتتبع النظر:** المطلوب التفات الشخصية نحو الجزء الذي يركز عليه الطالب من الشاشة/الكود. موضع النظر الدقيق غير متاح من Face Landmarker؛ يبقى المطلوب تقدير اتجاه تقريبي اختياري ولا يُعرض كتتبع دقيق للسطر.
- [ ] **تصحيح حي وإبراز الخطأ:** المطلوب اكتشاف syntax مع السطر والعمود، إظهار هالة حمراء حول الخطأ، والتفات الشخصية والإشارة إليه؛ التنفيذ الحالي لا يضمن تشخيصًا كاملًا ولا حركة يد. يلزم محرر/محلل وتشخيصات دقيقة وربط بصري وتحريك 3D متوافق.
- [ ] **مسح الشاشة والانتقال بين الدروس:** المطلوب حركة يد دائرية تمسح الأكواد بتأثير جسيمات عند الانتقال أو المسح، ثم يظهر الدرس الجديد. المتاح محليًا هو تأكيد المسح واستعادة النص؛ الحركة المرتبطة بالذراع والجسيمات لم تُنفذ بعد، ولا يجوز المسح دون تأكيد/تراجع.
- [ ] **المكافآت والاحتفال ثلاثي الأبعاد:** المطلوب High-Five/تعديل الطربوش، وإظهار كأس أو نجمة متوهجة ثلاثية الأبعاد ترتفع من اليد وتنتقل إلى لوحة النقاط. هذه النسخة يمكنها حفظ النقاط محليًا فقط؛ حركات الذراع المقنعة وأصل المكافأة ومسارها ثلاثي الأبعاد تبقى غير مفعلة.
- [ ] **التحية والذاكرة:** المطلوب الترحيب باسم الطالب واستعادة آخر درس ونقاطه عند عودته. المنفذ الممكن ملف يدوي محلي؛ كشف الوجه لا يحدد الهوية. لا يُنشأ قالب وجه أو تعرف بيومتري في هذه النسخة؛ أي خيار كهذا يحتاج موافقة منفصلة وخيار حذف وبديل يدوي.

- [ ] حفظ نقطة إصدار WebDev على `main` وتأكيد SHA بعد دفعها؛ لا يعني ذلك نشرًا عامًا.
