# 🎓 منصة مستر نقراشي — معلم بايثون الهولوجرام

مجسم ثلاثي الأبعاد لمستر نقراشي (بدلة + طربوش + نضارة) بيظهر كهولوجرام نيون، بيشرح بايثون بالصوت، بيتحرك فمه مع الكلام، وبيتفاعل مع حركات إيدك قدام الكاميرا.

## التشغيل

```bash
cd frontend
python3 tools/generate_assets.py     # مرة واحدة: بيولّد المجسم والخامة والمؤثرات الصوتية (موجودين جاهزين في الـ zip)
python3 -m http.server 8080
```

افتح **http://localhost:8080** في Chrome أو Edge، واضغط «ابدأ الحصة».

> لازم تشغّله من سيرفر (localhost أو https) — مش بفتح الملف مباشرة — عشان الشيدرز والكاميرا والمايك.
> محتاج إنترنت لتحميل Three.js و MediaPipe و Pyodide من الـ CDN.

## الهيكل

| الملف | وظيفته |
|---|---|
| `index.html` / `style.css` | لوحة التحكم الزجاجية (Glassmorphism + نيون) |
| `src/hologram_3d.js` | Three.js: تحميل المجسم، الإضاءة والبيئة، Bloom، الأنيميشن (سلام، إشارة، هز راس، احتفال، رمشة) |
| `src/shaders/*.glsl` | شيدر الهولوجرام: Fresnel، خطوط مسح، وميض، Glitch، ودعم الـ Blend Shapes |
| `src/hand_tracking.js` | MediaPipe Hands + تصنيف الإيماءات |
| `src/audio_handler.js` | المايك + التعرف على الكلام + نطق الردود + Lip-Sync (Visemes) |
| `src/ui_effects.js` | أصوات الواجهة، مطر الأكواد، توهج الزجاج، الإشعارات |
| `src/curriculum.js` | **إضافة**: منهج بايثون (١٢ درس، كل درس له شرح سطر بسطر وسؤال اختيار) + أسئلة شائعة + شرح الأخطاء |
| `src/progress.js` | **إضافة**: نقاط الخبرة (XP) والمستويات وسلسلة الأيام وحفظ التقدم في المتصفح |
| `src/certificate.js` | **إضافة**: شهادة إتمام المنهج بالاسم (صورة PNG) |
| `src/app.js` | المايسترو اللي بيربط كل ده |
| `tools/generate_assets.py` | **إضافة**: بيولّد الأصول الأولية |

## المنهج والتقدم

١ الطباعة · ٢ المتغيرات · ٣ الشرط · ٤ for · ٥ الدوال · ٦ القوائم · ٧ while · ٨ القواميس · ٩ النصوص · ١٠ اللوب على قائمة · ١١ دالة بشرط · ١٢ تحدي FizzBuzz.

- بعد كل درس سؤال اختيار من متعدد.
- النقاط: ١٥ XP للحل من غير تلميح، ١٠ مع تلميح أو محاولة غلط، ٣ لو استخدم الحل الجاهز، +٥ للإجابة الصح على السؤال، +٢٥ لإنهاء المنهج. كل ٤٠ XP مستوى جديد.
- التقدم وسلسلة الأيام بيتحفظوا في المتصفح، والطالب بيكمّل من آخر درس. زر «إعادة ضبط التقدم» بضغطتين.
- بعد الدروس الـ١٢ بتتفتح شهادة بالاسم، وتقدر تنزّلها صورة.
- لو عدّلت ترتيب الدروس: التقدم محفوظ بأرقام الدروس، فأضف الدروس الجديدة في الآخر.

## استبدال المجسم بالنسخة الحقيقية

ضع ملف `.gltf` أو `.glb` مكان `assets/models/mr_nokrashy.gltf` (أو غيّر `modelUrl` في `hologram_3d.js`) وخلّي الأسماء كده:

- Nodes: `Head` · `ArmR` · `ArmL` · `EyeL` · `EyeR`
- Blend Shapes للفم: `jawOpen` · `mouthWide` · `mouthRound` · `mouthSmile`
  (أو المكافئ: `mouthOpen`, `viseme_aa`, `viseme_O`, `viseme_E`)
- الأجزاء اللي اسمها فيه `Tarboosh` أو `Tassel` بتتلوّن أحمر تلقائياً، و`BowTie` بالماجنتا، و`Glasses`/`Eye` بالأصفر.

لو الملف مش موجود، التطبيق بيبني مجسم احتياطي بالكود.

## ربط باك إند (ذكاء اصطناعي)

في `src/app.js` غيّر `CONFIG.apiUrl` لعنوان الـ API بتاعك:

```
POST  { "message": "...", "lesson": "loops", "code": "..." }
→     { "reply": "نص الرد", "audio_url": "اختياري: رابط صوت جاهز" }
```

لو رجّع `audio_url` بيتشغّل ويتحرك الفم من شدة الصوت. تسجيل صوت الطالب بيتخزن في `state.lastRecording` كـ Blob جاهز للإرسال.

## ملاحظات

- التعرف على الصوت (`ar-EG`) شغال في Chrome و Edge. وجود صوت عربي للنطق بيعتمد على النظام؛ لو مفيش، الفم بيتحرك بتوقيت تقديري.
- الكاميرا والمايك مش بيشتغلوا غير بعد ما الطالب يدوس الزر بنفسه.
- الكود بيتنفذ جوه المتصفح بـ Pyodide (أول تشغيل بياخد ثواني للتحميل). `input()` مش مدعومة.
